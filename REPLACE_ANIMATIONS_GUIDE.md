1. **Go to LottieFiles.com**

2. **Search for animations:**
   - Screen 1: Search "AI brain" or "artificial intelligence"
   - Screen 2: Search "technician" or "worker"
   - Screen 3: Search "smart home" or "home automation"

3. **Download JSON files:**
   - Click on animation you like
   - Click "Download" → "Lottie JSON"
   - Save the file

4. **Replace files:**
   ```
   Replace: assets/images/image1.json
   Replace: assets/images/image2.json
   Replace: assets/images/image3.json
   ```

5. **Run app:**
